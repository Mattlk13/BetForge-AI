# ForgeAI integration

BetForge can use ForgeAI for software work, sports-data analysis, simulations, research, and documentation.

Adapter: `functions/lib/forgeai.ts`

Configure server-side `FORGEAI_BASE_URL` and `FORGEAI_API_KEY`.

ForgeAI must not place wagers, bypass age/geographic controls, or present uncertain predictions as guaranteed outcomes. Any regulated wagering functionality remains subject to jurisdiction, licensing, and platform requirements.
